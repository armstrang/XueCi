= S | "是"字句 | A + 是 + B
t: 1
v: h2 1, yct 1, bct A
i: 1-036
n: shì zì jù | Bilang "adalah": 是 | Saying "is": 是 | พูดว่า "เป็น / คือ": 是 | Nói "là": 是
fs: 主语 + 是 + 名词
w: Jangan pakai 是 di depan kata sifat: 她很高, bukan 她是高. | Don't put 是 before an adjective: 她很高, not 她是高. | อย่าใช้ 是 หน้าคำคุณศัพท์: 她很高 ไม่ใช่ 她是高 | Đừng dùng 是 trước tính từ: 她很高, không nói 她是高.
k: 是
id: 是 menyamakan dua kata benda: 我是老师. Tidak dipakai di depan kata sifat.
en: 是 links two nouns: 我是老师. It isn't used before an adjective.
th: 是 เชื่อมคำนามสองคำ 我是老师 ไม่ใช้หน้าคุณศัพท์
vi: 是 nối hai danh từ: 我是老师. Không dùng trước tính từ.
e: [1 我] [2 是] [3 学生] 。
e: [1 这] [2 是] [3 我 的 书] 。
